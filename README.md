# Oriel: лендинги

Все страницы Oriel на GitHub Pages. Обновляются сами через минуту после push в `main`.

| Страница | Ссылка | Для чего |
|---|---|---|
| Главный лендинг | https://cxlvcl.github.io/oriel-presentation/ | Oriel целиком: проблема, миссия, как работает, «Помощь», для кого, пилот в вузе, модель. 3D-iPhone с экранами, листается скроллом |
| Речь для питча | https://cxlvcl.github.io/oriel-presentation/speech/ | Речь на 3 минуты, версия на 30 секунд и вкладка «Вопросы»: 20 ответов жюри с поиском. Секундомер и крупный шрифт. Тексты Виталия: речь в `vault/Pitch/` (ветка `backend`), ответы в `qa/` |
| Презентация для питча | https://cxlvcl.github.io/oriel-presentation/pitch/ | 12 слайдов под речь в стиле приложения: шрифт SF Pro, крупный текст, плоские карточки. Листать ← →, пробелом или кликом; F — полный экран. Работает без интернета |
| Анкета студентов | https://cxlvcl.github.io/oriel-presentation/survey/ | Для iPad на форуме: вводим ответы студентов, сверху итоги в процентах. Внизу отдельная форма рассылки. Всё хранится на этом iPad, кнопка «Скопировать всё» |
| Памятка по опросу | https://cxlvcl.github.io/oriel-presentation/survey/memo.html | Как начать разговор, 11 вопросов по порядку и что сказать в конце |

## Файлы

- `index.html`, `land.js`, `screens/` — главный лендинг (`land.js` — карта суши для сферы из точек, `screens/` — экраны из прототипа)
- `speech/` — речь для питча
- `pitch/` — презентация под речь (один файл, шрифты внутри)
- `survey/` — анкета и памятка
- `qa/` — шпаргалка: ответы на вопросы после питча (текст; на сайте — вкладка «Вопросы» в `speech/`). Исходник — `vault/Pitch/` в ветке `backend`
